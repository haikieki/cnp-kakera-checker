Overview
ツール概要

CNP RED（Solana NFTコレクション）と CNP×RED° KAKERA NFT に関する情報を調べるためのツールです。以下の4つのタブ機能を提供しています。

タブできること
🔥 カケラ交換チェッカーウォレットアドレスを一括入力して、カケラ交換回数・最終交換日時を調べる
🔍 個体番号検索CNP REDコレクションを個体番号・レア特性・ウォレット別に検索する
🏆 コンプリートチェック複数ウォレットが9キャラクター全員を保有しているか確認する
💎 KAKERA保有チェックウォレットが保有するKAKERA NFTとキャラクターを確認する
💡 各タブの結果はすべて スプレッドシートに出力 できます。出力にはGAS（Google Apps Script）の設定が必要です。
Tab 1
🔥 カケラ交換チェッカー
複数アドレスの交換回数を一括確認

複数のウォレットアドレスを一度に入力して、各アドレスのカケラ交換回数・最終交換日時を取得します。

使い方

  1. テキストエリアにウォレットアドレスを1行に1つ貼り付ける
  2. 「🔍 一括検索」ボタンを押す
  3. 結果が交換回数順に一覧表示される
  4. 「詳細 ▼」を押すと各アドレスの送付履歴（カケラ種類・日時・TXリンク）が展開される

フィルター・並び替え

項目説明
最小交換回数指定回数以上のアドレスのみ表示
最大交換回数指定回数以下のアドレスのみ表示
並び順交換回数 多い順 / 少ない順 / 最終交換日時 新しい順・古い順 / アドレス昇順
✅ アドレス横の「📋」ボタンでウォレットアドレスをコピーできます。
Tab 2
🔍 個体番号検索
CNP REDコレクションを条件で検索

Helius APIを使用してCNP REDコレクション全件を取得し、条件に合うNFTを保有するウォレットを一覧表示します。

⚠️ 初回はコレクション全件（数千件）を取得するため時間がかかります。取得後はキャッシュされます。

KAKERA NFTを CNP RED に交換したアドレスを特定するには、以下の手順で行います。 個体番号2001以上がKAKERANFTとCNPREDを交換して得た個体に該当します。

📊 スプレッドシート出力
  1. 「🔍 個体番号検索」タブ を開く
    → 個体番号検索サブタブで 2001 を入力して検索
  2. 検索結果に表示されたウォレットアドレスをすべてコピーする
    →「📊 スプレッドシートに出力」でシートに書き出してからコピーすると楽
  3. 「🔥 カケラ交換チェッカー」タブ に切り替える
    → テキストエリアにコピーしたアドレスを貼り付ける
  4. 「🔍 一括検索」を押して交換回数・最終交換日時を確認する
    →「📊 スプレッドシートに出力」で記録に残す
✅ なぜ個体番号2001以上か？
CNP RED の通常発行分は個体番号 2000 番以下です。2001 番以降はKAKERA NFTとCNP REDを交換して発行された個体のため、これを保有するウォレットが「交換を行ったアドレス」として特定できます。

GAS再デプロイが必要なケース

GASのコードを更新した場合は必ず以下の手順で再デプロイしてください。

  1. GASエディタ右上の「デプロイ」をクリック
  2. 「デプロイを管理」を選択
  3. 鉛筆アイコン（編集）をクリック
  4. バージョンを 「新しいバージョン」 に変更
  5. 「デプロイ」をクリック（URLは変わりません）
