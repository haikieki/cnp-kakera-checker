# CNP RED ツール（カケラ交換チェッカー）

CNP RED の NFT に関する確認作業をブラウザだけで行えるツールです。
プログラムのインストールは不要で、HTMLファイル1つで動きます。

- **公開ページ**: https://cnp-kakera-checker.netlify.app （Netlify というサービスで公開中）
- **使い方の説明書**: `manual.html` をブラウザで開くと、画面付きの説明が読めます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `cnpred-kakera-checker.html` | ツール本体。これ1つで全機能が動く |
| `manual.html` | 利用者向けの説明書ページ |
| `README.md` | このファイル（引き継ぎ用の説明） |

## ツールでできること（4つのタブ）

1. **🔥 カケラ交換チェッカー** — ウォレットアドレス（NFTの持ち主の口座番号のようなもの）を複数まとめて貼り付けて、カケラ交換の回数を一括確認する
2. **🔍 個体番号検索** — 指定した個体番号以上の NFT を持っている人を探す。レア特性（ホロ・レインボー・アーマー）での絞り込みもできる
3. **🏆 コンプリートチェック** — キャラクターを全種類そろえているかを確認する
4. **💎 KAKERA保有チェック** — KAKERA NFT の保有状況を確認する

検索結果は Google スプレッドシートに書き出すこともできます。

## 裏側で使っている外部サービス（引き継ぎ時に要確認）

このツールは以下の外部サービスとつながっています。**引き継ぎの際は、それぞれの管理権限を誰が持つかの確認が必要です。**

### 1. Helius（NFTのデータを取り出すサービス）
- ブロックチェーン上の NFT 情報を取得するために使用
- 利用キー（合いカギのような文字列）が `cnpred-kakera-checker.html` の中に直接書かれています
  - 場所: ファイル内で `HELIUS_API_KEY_PRESET` と検索すると見つかります
- **引き継ぎ後は、新しい担当者が https://www.helius.dev/ で自分のキーを無料取得し、この部分を書き換えるのがおすすめです**（前任者のアカウントに紐づいたままにしないため）

### 2. Google スプレッドシート + Apps Script（検索結果の書き出し先）
- 書き出し先シート: `cnpred-kakera-checker.html` 内の `SHEET_URL` に URL が書かれています
- 書き出しの仕組み（Apps Script）の URL は `GAS_EXPORT_URL` に書かれています
- **どちらも Google アカウントに紐づいているため、シートと Apps Script の所有権を引き継ぎ相手に共有・移譲する必要があります**

### 3. カケラ交換データのサーバー（Google Cloud Run）
- カケラ交換チェッカーのデータ取得元: `API_BASE` に URL が書かれています
- このサーバーは別途 Google Cloud 上で動いており、**その管理アカウントも引き継ぎ対象です**

### 4. Netlify（ページの公開場所）
- 公開サイト名: `cnp-kakera-checker`
- **Netlify のアカウント権限がないと、ページの更新ができません**

## 更新のしかた（ざっくり）

1. `cnpred-kakera-checker.html` を編集する
2. Netlify にアップロードし直すと、公開ページに反映される
   - Netlify の管理画面（ https://app.netlify.com/ ）を開き、対象サイトにファイルをドラッグ&ドロップするだけでも更新できます

## 注意事項

- この保管場所（リポジトリ）は現在 **公開設定** です。ツール内に Helius の利用キーが直接書かれており、誰でも見られる状態です（公開ページの中身からも元々見える状態のため、公開範囲は実質同じです）。
- キーが他人に使われて上限に達した場合は、https://www.helius.dev/ で新しいキーを無料発行し、`HELIUS_API_KEY_PRESET` の部分を書き換えてください。
- 本格的に運用する場合は、キーを書き換えたうえで非公開に戻すか、キーを外部から見えない形にする改修をおすすめします。
